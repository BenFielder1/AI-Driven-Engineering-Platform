### Conventions shared by every pack

- **API prefix:** backend routes live under `/api`. Health endpoints use the paths in the backend pack's `Health`
  section.
- **Contract:** {{CONTRACT?}} The contract is generated by the backend and committed. The frontend client is generated
  from it. Neither is edited except in the generator's exact shape.
- **Errors:** RFC 9457 problem details with an `errorCode` extension, using codes from the specification's error table.
- **Secrets:** never in the repository. Only `*.example` files hold placeholder values. AIDE sets real values on the
  platforms and in CI.
- **Versions:** use current stable versions you are confident exist, and pin the runtime versions in their version
  files.
