# 0.5.0: trackers, co-authorship and inference

Spec: [SPEC](../0.5.0/SPEC.md). Build log: [PROGRESS](../0.5.0/PROGRESS.md). Merged in PR #28.

Research notes: [commit co-authorship](../0.5.0/COMMIT_CO_AUTHORSHIP.md), [issue tracker connections](../0.5.0/ISSUE_TRACKER_CONNECTIONS.md) and [Microsoft Agent Framework](../0.5.0/MICROSOFT_AGENT_FRAMEWORK.md).

- **Issue tracker imports** from Jira, Linear, GitHub Issues and GitLab Issues, as read-only snapshots.
- **Commit co-authorship.** Commits, merges and tags carry a `Co-authored-by` trailer for the accountable person.
- **Stack inference and the Analysis phase.** A Stack Analyst writes a `stack_profile` that an Owner approves.
- **Shared deployment projects.** Parts on one platform form a deployment group.
- **PostgreSQL 18** for the product's own database.
