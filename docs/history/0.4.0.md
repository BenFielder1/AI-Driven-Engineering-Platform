# 0.4.0: stacks, hosts and databases

Spec: [SPEC](../0.4.0/SPEC.md). Build log: [PROGRESS](../0.4.0/PROGRESS.md). Draft: [DRAFT_SPEC](../0.4.0/DRAFT_SPEC.md). Merged in PR #27.

- **Stack composition** from a versioned catalog, with compatibility rules in the backend, replacing the 0.2.0 presets.
- **Specialist agents with pack skills.**
- **GitLab and Bitbucket Cloud**: sign-in, connections, repo picker, merge requests, CI status, releases and import.
- **Deployment platforms**: Vercel, Netlify, Cloudflare, GitHub Pages, Render and Railway, with an environment inventory and an origin model.
- **Managed databases**: Supabase, Render Postgres and Railway Postgres, per environment.
- **LLM choice** per deployment, with streaming and continued answers.
