# 0.2.0: release versions and integrations

Spec: [SPEC](../0.2.0/SPEC.md). Build log: [PROGRESS](../0.2.0/PROGRESS.md). Merged in PR #13. The AIDE logo source is in [`docs/0.2.0/brand`](../0.2.0/brand/aide-logo.svg).

- **Release versions.** Each release has a semver version with internal checkpoints. Rollback is limited to the version in development, and a released version is closed.
- **Import an existing repo.** A Repository Analyst writes a codebase summary first.
- **Repo tools for agents.** Read-only `list_files`, `read_file` and `search_code` on a credential-free snapshot.
- **Tech stack presets.** Retired in 0.4.0.
- **GitHub App.** Registered through the manifest flow. Background Git work uses short-lived installation tokens.
- **Per-user LLM connections**, merge strategies, check runs as review input and GitHub Releases.
- **Vercel deployments.** Preview in review, production on release, with promote and redeploy.
- A new UI shell with one page per lifecycle stage.
