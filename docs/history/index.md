# Version history

Each version is an increment on the one before. Earlier requirements stay in force unless a later spec amends them. The product was called AIDE until 0.6.0, when it became Tevrin.

Versions are numbered semver, `x.y.z`. The versions specified as v1 to v6 are 0.1.0 to 0.6.0; `vN` still appears in spec IDs and folder names (`docs/v1/`), and means 0.N.0. From 0.6.0 each version is released as a Git tag and a GitHub release ([Releases](../operations/releases.md)).

| Version | Theme | Spec and build log |
| --- | --- | --- |
| [0.1.0](v1.md) | The governed lifecycle | [SPEC](../v1/SPEC.md), [PROGRESS](../v1/PROGRESS.md) |
| [0.2.0](v2.md) | Release versions, repo import, GitHub App, Vercel | [SPEC](../v2/SPEC.md), [PROGRESS](../v2/PROGRESS.md) |
| [0.3.0](v3.md) | Next.js frontend and Railway | [SPEC](../v3/SPEC.md), [PROGRESS](../v3/PROGRESS.md) |
| [0.4.0](v4.md) | Stack composition, GitLab, Bitbucket, platforms, databases | [SPEC](../v4/SPEC.md), [PROGRESS](../v4/PROGRESS.md) |
| [0.5.0](v5.md) | Issue trackers, co-authorship, stack inference, PostgreSQL 18 | [SPEC](../v5/SPEC.md), [PROGRESS](../v5/PROGRESS.md) |
| [0.6.0](v6.md) | Tevrin: rename, brand, marketing site, docs site | Root [SPEC](https://github.com/BenFielder1/AI-Driven-Engineering-Platform/blob/main/SPEC.md), [PROGRESS](https://github.com/BenFielder1/AI-Driven-Engineering-Platform/blob/main/PROGRESS.md) |

The specs of 0.1.0 to 0.5.0 are frozen. They are never edited, except to fix links.
