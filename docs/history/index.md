# Version history

Each version is an increment on the one before. Earlier requirements stay in force unless a later spec amends them. The product was called AIDE until 0.6.0, when it became Tevrin.

Versions are numbered semver, `x.y.z`. The versions specified as v1 to v6 are 0.1.0 to 0.6.0; `V<N>` still appears in spec IDs (`D-V6-1`), and means 0.N.0. From 0.6.0 each version is released as a Git tag and a GitHub release ([Releases](../operations/releases.md)).

| Version | Theme | Spec and build log |
| --- | --- | --- |
| [0.1.0](0.1.0.md) | The governed lifecycle | [SPEC](../0.1.0/SPEC.md), [PROGRESS](../0.1.0/PROGRESS.md) |
| [0.2.0](0.2.0.md) | Release versions, repo import, GitHub App, Vercel | [SPEC](../0.2.0/SPEC.md), [PROGRESS](../0.2.0/PROGRESS.md) |
| [0.3.0](0.3.0.md) | Next.js frontend and Railway | [SPEC](../0.3.0/SPEC.md), [PROGRESS](../0.3.0/PROGRESS.md) |
| [0.4.0](0.4.0.md) | Stack composition, GitLab, Bitbucket, platforms, databases | [SPEC](../0.4.0/SPEC.md), [PROGRESS](../0.4.0/PROGRESS.md) |
| [0.5.0](0.5.0.md) | Issue trackers, co-authorship, stack inference, PostgreSQL 18 | [SPEC](../0.5.0/SPEC.md), [PROGRESS](../0.5.0/PROGRESS.md) |

The specs of 0.1.0 to 0.5.0 are frozen. They are never edited, except to fix links.
