# 0.6.0: Tevrin

Spec: [SPEC.md](https://github.com/BenFielder1/AI-Driven-Engineering-Platform/blob/main/SPEC.md). Build log: [PROGRESS.md](https://github.com/BenFielder1/AI-Driven-Engineering-Platform/blob/main/PROGRESS.md). These files move to `docs/0.6.0/` when the version is done, and the release is tagged `0.6.0`.

0.6.0 has no schema changes and no new API endpoints.

- **Rename.** The product is now Tevrin. The CLI command is `tevrin`, with `aide` kept as a deprecated alias. Internal identifiers keep the `aide` name, so sessions, tokens and webhooks keep working.
- **Brand and design system.** A hexagon mark, an indigo to cyan gradient on slate surfaces, Geist type, and light and dark themes. See [Brand](../brand.md).
- **App refresh.** A tidier shell and a Home dashboard with an onboarding checklist.
- **Marketing site.** Public pages, and redesigned sign-in and sign-up.
- **Documentation.** A short README, and this site, published to GitHub Pages.
- **Versions and releases.** Versions are numbered semver (this is 0.6.0; v1 to v5 became 0.1.0 to 0.5.0). Each release is a Git tag and a GitHub release, and publishing it deploys production. See [Releases](../operations/releases.md).
