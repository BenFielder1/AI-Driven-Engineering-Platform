# Brand

Tevrin's mark is a hexagon of six segments. The six segments are the six lifecycle phases, and the gaps between them are the approval gates.

## Logo files

| File | Use |
| --- | --- |
| [Lockup, light](0.6.0/brand/tevrin-lockup-light.svg) | Mark and wordmark on light backgrounds |
| [Lockup, dark](0.6.0/brand/tevrin-lockup-dark.svg) | Mark and wordmark on dark backgrounds |

The files live in `docs/0.6.0/brand/`. The README shows the light lockup with a `#gh-light-mode-only` fragment and the dark lockup with `#gh-dark-mode-only`, so the logo follows the theme the reader has chosen on GitHub. Other Markdown viewers (such as an editor preview) ignore the fragments and show both lockups.

## Colours

Roles are fixed. Exact values may shift slightly to keep text contrast at WCAG AA.

| Role | Light | Dark |
| --- | --- | --- |
| Background | `#FFFFFF` | `#020617` |
| Card or surface | `#F8FAFC` | `#0B1120` |
| Border | `#E2E8F0` | `#1E293B` |
| Foreground | `#0F172A` | `#F8FAFC` |
| Muted foreground | `#475569` | `#94A3B8` |
| Primary (buttons, links) | `#4F46E5` | `#818CF8` |
| Accent and focus ring | `#0891B2` | `#22D3EE` |

The brand gradient runs from indigo `#4F46E5` to cyan `#06B6D4`. Type is Geist Sans, with Geist Mono for code.

## Usage rules

- Put no text on the gradient.
- Use the gradient sparingly: the mark and a few highlights.
- Use the mono variant where one colour is needed, such as print, a favicon or a single-colour badge.
- Pick the light or dark lockup to match the background. Don't recolour or stretch the mark.
- Keep clear space around the mark of at least the width of one segment.
- Warning colours are never used for text.
- Status badges pair a colour with a dot and a label, so colour is never the only signal.
- Write the name as "Tevrin". Describe the code as "source available on GitHub", never "open source".
